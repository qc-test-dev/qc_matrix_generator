================================
QC Matrix Generator - Documentación
================================

Bienvenido a la documentación oficial de **QC Matrix Generator**, el sistema integral para gestión de matrices de testing y chatbot de soporte.

El proyecto incluye dos aplicaciones principales:

- **Web de Seguimientos (Matrix)**: Sistema profesional para crear, gestionar y ejecutar matrices de testing
- **Chat LLM (Streamlit)**: Chatbot inteligente con soporte mediante RAG (Retrieval-Augmented Generation)
